# wash 性能 / 启动 / 内存 持续优化计划（2026-11-07）

> 目标：在保持 **100% 逐字节兼容 MSYS2 bash 5.3** 的前提下，把启动时间、
> 内存占用继续压低，并把解释器性能优势扩大。数据先行，杜绝盲优化。

## 0. 当前基线（P0-1/P0-2 实测，`tests/perf/bench.sh`，commit `ba5485d`+，best-of-5）

| 指标 | bash 5.3.20 | wash | 比值 |
|---|---|---|---|
| arith-loop ×2000 | 164ms | 169ms | ~1.0x（两窗口 0.93/1.03x，噪声级） |
| builtin-echo ×500 | 160ms | 138ms | **0.86x** |
| fork-exec-true ×100 | 5371ms | 5305ms | 0.99x（Cygwin fork 下限） |
| cmdsub ×100 | 3175ms | 2811ms | **0.89x** |
| subshell ×100 / pipeline ×50 | 3003/4615ms | 2771/3959ms | 0.92x / **0.86x** |
| expand-heavy ×1000 | 158ms | 140ms | **0.89x** |
| **性能 TOTAL** | 16646ms | 15293ms | **0.92x** |
| **startup（50 次启动）** | 4760ms | 3951ms | **0.83x** |
| **内存 VmRSS（阻塞 read 进程）** | 10368KB | 8896KB | **0.86x（wash 更省）** |

**测量纪律（铁律级教训，2026-11-07 实测）**：本机噪声极大（同一用例 243ms↔24s 波动；
CLI 曾单轮 21/22 超时偶发）。一切结论必须 **同窗口 best-of-≥5 + 交错复测**；
任何「回退」必须沉降后重测证伪/证实，禁止凭单次读数下结论。
**内存探针注记**：勿用 `/dev/zero` 作 `read` 阻塞源（无限 NUL 会把 read 缓冲撑到
23MB，污染读数）；必须用无数据管道（`tail -f /dev/null | read x`）。

## 已落地的性能不变量（改动相关路径前必读，详见 2026-11-07 工作日志）

1. `execute()` 非交互且未开 `expand_aliases` 时**不克隆 AST**（借用 `list`）。
2. `ExpandCtx.attrs` 用 `AttrRefs` 借用视图（每命令 4 个 HashSet 深克隆曾是热点）。
3. `Prepared` **不持有 env 表**——只存 `env_values`；`build_cmd_env`/`build_shell_env`
   仅由真正 fork/exec 的路径调用（每命令双份 HashMap 克隆曾是 ~140µs/命令的大头）。
4. arith 求值走 `tokenize_cached`（thread_local 512 条，`Arc<Vec<Tok>>` 共享），
   `parse_primary` 借用缓存 Ident 不 clone。

## P1 启动时间（依 P0-3 数据定案）

- 候选：`populate_internal_variables`（BASH_xxx 内部变量表）惰性化/静态化；
  启动路径堆分配削减。

## P2 内存占用（✅ 验收天然达标：0.86x ≤ 1.5x）

- 保持现有优势；仅在 P1 改动波及时复核不回退。
- 可选深挖（低优先）：`Arc<str>` 共享 AST 字符串；与大环境变量场景的专项对拍。

## P3 解释器性能收尾（均已 <1.0x，锦上添花）

- `expand_word` 的 `WordPart::Text` 零拷贝（`Cow`/单缓冲追加）。
- `capture_command` 内部命令 tokenize/parse 缓存（cmdsub 0.98x → <0.9x）。
- **fork-exec（~0.97x）**：评估 posix_spawn/vfork 可行性；若受 Cygwin 平台天花板
  限制，实测记录后**明确不动**（它是本机所有 shell 的共同下限）。
